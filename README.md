## The pitch

## How it works

`main.ts` (Node 22, no dependencies) writes exactly one sentence to `/output/entry.txt`. Before writing, it mirrors the competition gate: the text must be 1–240 characters, not only white space, and exactly one sentence. The run is fully deterministic — the same sentence is written every time.

## How to run
